# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud data storage and the use of Object Storage. In this mission, I learned the differences between Block Storage, File Storage, and Object Storage. I also deployed an S3-compatible Object Storage server using MinIO and Docker, created a storage bucket, and uploaded a sample file.

## Objectives

* Differentiate Block Storage, File Storage, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console through a forwarded port.
* Create an Object Storage bucket.
* Upload a file to the created bucket.
* Document the cloud storage deployment using Markdown.
* Continue building my GitHub Cloud Computing portfolio.
