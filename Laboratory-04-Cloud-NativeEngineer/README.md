# Laboratory 04 - Cloud-Native Engineer

## Mission Overview

This laboratory activity introduces cloud-native engineering using Docker and containers. In this activity, I learned the difference between Virtual Machines (VMs) and containers and practiced using Docker in the KillerCoda Playground. I also deployed an Nginx web server inside a container and managed its basic lifecycle.

## Objectives

- Understand the difference between Virtual Machines and Containers.
- Access a Docker-enabled environment using KillerCoda.
- Practice basic Docker commands.
- Pull and run an Nginx container.
- Use port mapping to access a web server.
- Stop and remove a Docker container.
- Document Docker operations using Markdown.
- Continue building my Cloud Computing GitHub portfolio.
