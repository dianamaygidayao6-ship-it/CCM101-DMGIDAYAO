# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, networking, databases, containers, analytics, and artificial intelligence.

## Global Infrastructure

Google Cloud provides regions and zones across the world. Its global network and distributed infrastructure help organizations run applications with good performance, availability, and scalability.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create and manage Google Cloud projects, services, resources, and applications.

## Four Core Services

| Service | Purpose |
|---|---|
| Compute Engine | Provides virtual machines for running applications. |
| Cloud Storage | Provides object storage for files and data. |
| Google Kubernetes Engine (GKE) | Provides a managed Kubernetes environment for containers. |
| Cloud IAM | Controls access to Google Cloud resources. |

## Three Advantages

1. Google Cloud is strong in artificial intelligence and machine learning.
2. Google Cloud provides Google Kubernetes Engine for managed Kubernetes deployments.
3. Google has a large global network and infrastructure for scalable applications.

## Typical Enterprise Use Cases

- Artificial intelligence and machine learning
- Big data and analytics
- Containerized applications
- Global web applications
- Data storage and processing
