# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, networking, databases, identity, analytics, artificial intelligence, and enterprise applications.

## Global Infrastructure

Azure has a large worldwide infrastructure made up of regions and datacenters. Azure regions help organizations place applications and data in locations that can meet performance, availability, and data residency requirements.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services

| Service | Purpose |
|---|---|
| Azure Virtual Machines | Provides Windows and Linux virtual machines. |
| Azure Blob Storage | Stores large amounts of unstructured data and files. |
| Azure Virtual Network | Provides networking for Azure resources. |
| Microsoft Entra ID | Provides cloud identity and access management. |

## Three Advantages

1. Azure works well with Microsoft technologies such as Windows Server and Microsoft 365.
2. Azure provides many enterprise and hybrid-cloud services.
3. Azure has a large global infrastructure and many security and compliance features.

## Typical Enterprise Use Cases

- Migrating Windows Server workloads
- Connecting Microsoft 365 and enterprise applications
- Hosting business applications
- Running SQL Server workloads
- Creating hybrid cloud environments
