# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform from Amazon. It provides many cloud services for computing, storage, databases, networking, security, analytics, and other business needs.

## Global Infrastructure

AWS uses Regions and Availability Zones around the world. AWS Regions are separate geographic areas, while Availability Zones are isolated locations inside a Region. This design helps organizations build applications that are more available and fault tolerant.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources and services.

## Four Core Services

| Service | Purpose |
|---|---|
| Amazon EC2 | Provides virtual servers for running applications. |
| Amazon S3 | Provides scalable object storage for files and data. |
| Amazon VPC | Creates a private network environment for AWS resources. |
| AWS IAM | Controls users, roles, permissions, and access to AWS resources. |

## Three Advantages

1. AWS provides a very wide range of cloud services.
2. AWS has a large global infrastructure for applications used around the world.
3. AWS supports flexible and scalable solutions for different types of organizations.

## Typical Enterprise Use Cases

- Hosting websites and web applications
- Running business applications
- Storing company files and backups
- Building databases and data platforms
- Creating scalable e-commerce systems
