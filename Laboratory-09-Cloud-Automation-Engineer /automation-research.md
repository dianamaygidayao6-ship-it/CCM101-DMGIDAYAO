# Automation Research

## 1. Bash Script
A Bash script is a file containing Linux shell commands that can be executed together to automate a task. The line `#!/bin/bash`, called the shebang, tells the operating system which interpreter should run the script.

## 2. Variables
Variables store values such as folder paths and timestamps. Using a variable like `BACKUP_DIR` makes a script easier to update because the folder path can be changed in one place instead of editing many commands.

## 3. Cron Job
A cron job is a scheduled task in Linux that runs commands automatically at a specified time or interval. It is useful in cloud operations because it can schedule routine activities such as backups without requiring someone to run them manually.
