# Cloud Provider Comparison

## Core Infrastructure Services

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID / Azure RBAC | Cloud IAM |

---

## 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services. It provides many options for computing, storage, networking, databases, security, analytics, and other cloud technologies.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with many Microsoft products and services. It can make cloud management easier for organizations that already use Microsoft technologies.

## 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its AI, machine learning, and Kubernetes services. Google Cloud provides services such as Vertex AI and Google Kubernetes Engine.

## 4. What similarities did you observe among the three cloud providers?

The three cloud providers offer similar basic infrastructure services. All of them provide computing, storage, networking, and identity and access management services, although their names and features are different.
