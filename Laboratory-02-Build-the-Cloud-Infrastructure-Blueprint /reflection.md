# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, compute is one of the most important cloud infrastructure components because it provides the processing power needed to run applications and services. Without compute resources, applications would not be able to perform their tasks.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable operating system for servers. It also provides many command-line tools that administrators can use to manage servers, storage, networking, and applications.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the resources and configurations that will be used. It also helps engineers understand the system and makes troubleshooting and maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as `lscpu`, `free`, `lsblk`, `df`, and `ip addr`. I also learned how to identify cloud infrastructure components, compare cloud providers, create a cloud architecture diagram, and use Markdown for technical documentation.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized because I added a new laboratory folder containing my reports, documentation, screenshots, and cloud architecture diagram. It also shows my progress and the skills I learned in Cloud Computing.
