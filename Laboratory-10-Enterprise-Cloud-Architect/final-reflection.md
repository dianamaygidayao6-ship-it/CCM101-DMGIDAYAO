Final Reflection: Missions 1–10

Throughout Missions 1–10, I gained a better understanding of how cloud computing concepts and tools are used to build, manage, and maintain infrastructure. These activities introduced me to cloud platforms, Linux administration, Docker containers, object storage, Infrastructure as Code, system monitoring, and automation. I applied what I learned by setting up an Ubuntu Server virtual machine in VirtualBox and deploying WordPress and MariaDB using Docker Compose.

I also configured UFW firewall rules, used Docker volumes to keep database data persistent, and created a Bash script to back up the database automatically through a scheduled cron job. One of the most important lessons I learned is that an application should not only work properly but also be secure, reliable, and easy to maintain. Persistent storage helps protect data when containers restart, while regular backups make data recovery possible in case of unexpected problems.

During these missions, I also learned how to check system logs, verify firewall settings, document configurations, and troubleshoot technical issues. These experiences improved my problem-solving skills and increased my confidence in using Linux and Docker.

Overall, Missions 1–10 helped me understand the importance of cloud infrastructure and system administration. Through the CloudNova project, I was able to combine the knowledge and skills I gained into one working system and create documentation that can help other administrators understand, manage, and maintain the infrastructure.
