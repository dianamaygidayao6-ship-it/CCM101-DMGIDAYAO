# Laboratory 10: Enterprise Cloud Architect

## Mission Overview
This project demonstrates the deployment and management of a secure, multi-tier cloud application using Ubuntu Server, Docker, Docker Compose, WordPress, and MariaDB.

## Objectives
- Design a cloud infrastructure architecture.
- Deploy WordPress and MariaDB using Docker Compose.
- Configure UFW firewall security.
- Configure persistent database storage.
- Automate database backups using Bash and cron.
- Document system deployment, security, and maintenance.

## Technologies Used
- VirtualBox
- Ubuntu Server
- Docker
- Docker Compose
- WordPress
- MariaDB
- UFW Firewall
- Bash and cron
- GitHub

## Project Files
- `README.md` — project overview.
- `architecture-diagram.png` — infrastructure architecture diagram.
- `docker-compose.yml` — application and database configuration.
- `automation-script.sh` — automated database backup script.
- `operational-manual.md` — deployment and maintenance instructions.
- `final-reflection.md` — reflection on Missions 1–10.

## Application Access
When the VM and services are running, access the WordPress website at:

`http://127.0.0.1:8082`

This address works from the host computer when VirtualBox port forwarding is configured correctly.

## Security Notice
Credentials and other sensitive information must not be published in the repository.
